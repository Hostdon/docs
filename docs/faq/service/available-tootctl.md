# 実施可能な tootctl（Mastodon サーバータスク）を教えて

Hostdon では、以下の `tootctl` コマンドをコントロールパネルより実施可能です。

---

## 管理者ユーザーの追加  
### コマンド：`tootctl accounts create`

入力されたユーザー名で、**管理者権限を持つユーザー**を新規作成します。  
このユーザーは Mastodon の管理画面にアクセスでき、全体設定やモデレーション操作が可能です。

---

## ユーザーへのロールの付与  
### コマンド：`tootctl accounts modify`

指定したユーザーに、以下のいずれかのロールを付与できます。

- `owner`（オーナー権限）  
- `admin`（管理者権限）  
- `moderator`（モデレーター権限）

また、ロールを削除して**一般ユーザーに降格**させることも可能です。  

詳しくは [ロールについて](../../manual/mastodon/about-role.md) をご覧ください。

---

## カスタム絵文字の登録  
### コマンド：`tootctl emoji import`

`.tar.gz` アーカイブから**カスタム絵文字**を一括インポートします。

- 含まれるファイル形式：**PNG** または **GIF**  
- ファイルサイズ：**1ファイルあたり 50KB 以下**  
- ショートコード：**ファイル名（拡張子を除く）**が自動で設定されます  

### パスの例


以下のようなアーカイブを用意します：
```
hoge.tar.gz
├─ hogehoge.png
├─ nyan.gif
└─ smile.png
```
上記のアーカイブを登録すると、  
それぞれ次のように絵文字として登録されます：

| ファイル名 | 登録されるショートコード |
|-------------|---------------------------|
| hogehoge.png | `:hogehoge:` |
| nyan.gif | `:nyan:` |
| smile.png | `:smile:` |
