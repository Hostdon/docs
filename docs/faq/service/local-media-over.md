# ローカルメディア容量がオーバーした場合、どうなりますか？

ローカルメディア容量がオーバーした場合、次回の契約更新時に自動的に **「メディア増量（50GB）」** が契約されます。  

なお、「メディア増量（50GB）」を契約後、ローカルメディア容量が制限容量内まで減った場合は、  
**「メディア増量（50GB）」を契約解除** することができます。

---

## 具体例

- 4/1 にライトプランを契約し、5/15 にローカルメディア容量が上限（10GB）を超えた場合  
  → 6/1 の更新時に「ライトプラン + メディア増量（50GB）」が請求されます。  

- その後、6/12 にローカルメディア容量が再び 10GB 未満に減った場合  
  → 7/1 以降に「メディア増量（50GB）」を解除することができます。

---

## 注意事項

- 「メディア増量（50GB）」の追加・解除は請求期間単位で行われます。  
- 容量オーバー状態が続く場合、再度自動的にメディア増量プランが適用されます。  
- データ削除のみでは即時の請求反映は行われません。
