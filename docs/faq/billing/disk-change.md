# ディスク追加プランを変更した場合、支払いはどのように計算されますか？

ディスク追加プランを変更した場合、**変更確定日を基準に日割りで差額を計算**します。  
差額の扱いは、**ディスク追加プランを追加した場合**と、**ディスク追加プランを解約する場合**で異なります。


## ディスク追加プランを追加した場合

- 新しいディスク追加プランが変更確定日に適用されます。  
- 現在の請求期間の残り日数に応じて、**差額分が日割りで計算され、次回請求時に追加**されます。  
- **例：**  
  月の途中で「ディスク追加プラン」を1つから2つに追加した場合、残り期間分の差額が次回請求に上乗せされます。


## ディスク追加プランを解約する場合

- ディスク追加プランが変更確定日に解約されます。  
- 現在のディスク追加プランの未使用期間に相当する金額は、**クレジット（残高）として処理**され、次回以降の請求に自動的に充当されます。  
- クレジットの払い戻し（現金返金）は行われません。


## 変更確定日とは

- ディスク追加プラン変更の申し込み後、即時に反映されるわけではなく、運営チームによる変更作業と確認が完了した時点で正式にディスク追加プランが切り替わります。  
- この切り替えが完了した日時を**変更確定日**と呼びます。  
- 請求計算や差額の日割りは、この変更確定日を基準に行われます。
